# ネイルサロン（Nail Salon Sample）の作業ルール

## 守ること
- 答えは日本語で書く
- やわらかい言葉づかいにする（お客様向けの文章も、説明の文章も）
- 色はお店の雰囲気に合わせる
  - いつもの色：ベージュ＋ゴールド
  - 色の設定は `style.css` のいちばん上（`:root`）にまとめてある。新しい色もここに足す
  - 季節の飾り（今はクリスマス）は `style.css` の「クリスマス期間用」のところにまとめる
- お客様の名前や電話番号は書かない
  - ホームページ、ブログ、Instagram の文章、コード、メモのどれにも書かない
  - 例を出すときも、本物の情報は使わない

## お店のこと
- 店名・予約方法・これまでに作ったものは `HANDOFF.md` にまとめてある
