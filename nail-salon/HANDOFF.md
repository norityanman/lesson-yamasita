### 3. 1ページのホームページ（index.html）
- ベージュ＋ゴールド系（文字・ボタン #80612A、飾り線 #C2A15A）、スマホ対応
- 並び：ヘッダー → スタッフ募集 → メインビジュアル（店名＋予約ボタン）→ お店について → メニューと料金 → 営業時間（＋予約ボタン）→ フッター
- 色は `:root` の CSS 変数でまとめて変更可
- クリスマス仕様：`<body class="xmas">` の `xmas` を消すと通常デザインに戻る（CSS は「クリスマス期間用」ブロックにまとめてある）

### 4. 空き状況ページ（reserve.html）
- 空いている日をカレンダーで選ぶ → ホットペッパーの予約画面へ進む仕組み（予約そのものはホットペッパーのまま）
- 今月と来月を表示。過ぎた日・満席・休みの日は押せない
- 見た目の設定はトップページと共通の `style.css` にまとめた
- **空き状況の更新は `availability.js` を書きかえるだけ**
  - 1日1行：`"2026-12-05": "空き",`
  - 使える言葉は「空き」「残りわずか」「満席」「休み」の4つ
  - 書いていない日は「ホットペッパーでご確認ください」と出る
  - いま入っているのは見本のデータ。公開前に実際の予定に書きかえる
- ホットペッパーの店舗URLも `availability.js` のいちばん下で書きかえる
