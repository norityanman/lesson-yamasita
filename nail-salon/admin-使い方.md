# 予約の管理ページの使い方（オーナーさん用）

ホットペッパーから届いた予約のメールを使って、ホームページの空き状況（◎△×）を変えるページです。
パソコンで `nail-salon` フォルダの **`admin.html`** を開くだけで使えます。インターネットにつながっていなくても動きます。

---

## ふだんの使い方

1. **メールをコピーする**
   ホットペッパーから届いた「予約が入りました」「キャンセルされました」「変更されました」のメールを開いて、文章をぜんぶコピーします。

2. **貼りつけて「読みとる」を押す**
   管理ページの①の四角に貼りつけて、「読みとる」を押します。
   貼りつけた文章は、押したらすぐに消えます。

3. **お知らせを見て選ぶ**
   ②に「12月5日（土）△ 残りわずか → × 満席　空き状況を変えますか？」のように出ます。
   - **OK（変える）**：空き状況を変えて、予約の件数も数えます。
   - **変えない**：何も変わりません。空き状況も件数もそのままです。

4. **ホームページに反映する**
   ③の「新しい availability.js を保存する」を押すと、ファイルが保存されます（たいていは「ダウンロード」フォルダに入ります）。
   そのファイルを `nail-salon` フォルダに入れて、今の `availability.js` と入れかえてください。
   - 名前が `availability (1).js` のようになっていたら、`availability.js` に直してから入れかえます。
   - 入れかえたあとに管理ページを開き直すと、③の一覧が空になります。それが「反映できた」しるしです。

メールが何通かたまっていたら、1〜3を1通ずつくり返して、最後に4を1回だけすれば大丈夫です。

---

## こんなときは

| こんなとき | 出るお知らせ・どうするか |
|---|---|
| 同じメールを2回貼りつけた | 「もう読みとりずみです」と出て、何も変わりません。 |
| 予約のメールではないものを貼りつけた | 「読めませんでした」と出て、何も変わりません。 |
| お休みの日に予約が入った | 「お休みになっています」と出ます。空き状況は「休」のままです。特別に開ける日なら、`availability.js` を手で直してください。 |
| 過ぎた日のメールだった | 空き状況は変えません。 |
| このページを使い始める前の予約がキャンセルされた | 「記録にありません」と出ます。件数がわからないので、空き状況を自分で確かめてください。 |
| OK したけど、やっぱりやめたい | ③の一覧の「取り消す」を押します（ファイルを保存する前なら取り消せます）。 |

---

## 設定

⑤で、1日に何件の予約で △ や × にするかを変えられます。
はじめは **1件で △（残りわずか）、2件で ×（満席）** になっています。

---

## 予約の締め切り（前の日の18時）

- 空き状況ページでは、**前の日の18時ちょうど**になると、次の日のマスが「締切」になって押せなくなります。
  - 例：12月5日の予約は、12月4日の17:59までなら選べます。18:00からは「締切」です。
  - 今日の日にちは、いつも「締切」になります。
  - ページを開いたままでも、18時になると自動で「締切」に変わります。
- 管理ページでは、締め切りを過ぎた日の予約メールを読みとると「締め切りを過ぎた日です」と注意が出ます。
- 時間を変えたいときは、`availability.js` のいちばん下の `window.CUTOFF_HOUR = 18;` の数字を書きかえます（17時にするなら `17`）。

---

## 締め切りを練習でためす

夜の18時まで待たなくても、ためせます。

1. 管理ページの⑥「練習用：いまの日時を決めてためす」で、日時を入れます。
   - 例：`2026/12/04 17:59`
2. 「この日時で空き状況ページを開く」を押します。
   - 12月5日が押せることを確かめます。
3. 日時を `2026/12/04 18:00` に変えて、もう一度押します。
   - 12月5日が「締切」になって押せないことを確かめます。
4. 管理ページでもためしたいときは「この日時で管理ページを開く」を押して、見本のメールを貼りつけます。

- 練習中は、ページのいちばん上に**青い帯で「練習モード」**と出ます。
- 練習中の記録は、本物の記録とは別に残ります。本物の記録にはまざりません。
- 練習が終わったら「練習をやめて、本当の時刻にもどす」を押してください。
- 本当の時刻や、お客様が見る画面は変わりません。

## 知っておいてほしいこと

- **お客様の名前や電話番号は残りません。** このページが取り出すのは、予約番号と日にちだけです。予約番号は、キャンセルや変更のときに、どの予約かを見分けるためだけに使います。
- **記録は、このパソコンのこのブラウザの中だけにあります。** ほかのパソコンやスマホで開くと、記録は空っぽです。ブラウザの「閲覧データを消す」をすると、記録も消えます。
- **このページを使い始める前の予約は数えられていません。** はじめのうちは、お知らせの件数が少なく出ることがあります。おかしいと思ったら「変えない」を選んでください。
- **このページはお客様に見せないでください。** ホームページを公開するときは、`admin.html` は公開する場所に入れないでください。
- **本物のメールで読めるかは、まだ確かめていません。** 今は練習用の見本（`samples` フォルダ）で作ってあります。本物のメールで「読めませんでした」と出たら、名前と電話番号を消したメールを1通見せてください。読めるように直します。

---

## 練習してみる

`samples` フォルダに、練習用の作りもののメールが入っています。上から順番に貼りつけると、ひと通りためせます。

1. `1-予約.txt`（12月5日に予約）
2. `2-予約2件目.txt`（12月5日に2件目の予約）
3. `3-キャンセル.txt`（2件目がキャンセル）
4. `4-日にち変更.txt`（1件目が12月10日に変更）
5. `5-読めないメール.txt`（予約ではないお知らせ）

練習が終わったら、⑤の「記録をぜんぶ消す」で元にもどせます。
