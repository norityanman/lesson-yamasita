# 予約管理のしくみ　説明書

## 1. なぜ作るのか
- 今、予約はホットペッパーで受けています。
- ホームページの空き状況（◎△×）は、それとは別に手で書きかえています。
- 同じことを2回書くのは手間がかかります。書き忘れると、ホームページとホットペッパーで空き状況がちがってしまいます。
- ホットペッパーから届く予約のメールを使って、ホームページの空き状況をそろえやすくしたいです。

## 2. 誰が使うか
- **オーナー（ネイリスト）**
  - お知らせを見て、OK を押す人です。
  - ふだんはスマホで使います。
- **お客様**
  - ホームページで空き状況を見る人です。
  - しくみを直接さわることはありません。

## 3. 必ずほしいこと
1. **メールを読む**
   - ホットペッパーから届く予約とキャンセルのメールを読んで、「何月何日に予約が入った（なくなった）」をひろい出します。
2. **確かめてから更新する**
   - すぐには変えず、まずオーナーにお知らせします。
     - 例：「12月5日（土）に予約が1件入りました。空き状況を ◎ から △ に変えますか？」
   - OK を押したときだけ、ホームページの空き状況が変わります。
   - 「変えない」も選べます。
3. **キャンセルにも対応する**
   - キャンセルのメールが来たら、「△ から ◎ にもどしますか？」とお知らせします。
4. **お客様の名前や電話番号は出さない**
   - メールに書いてあっても、ホームページ、お知らせ、記録のどこにも書きません。
   - しくみが使うのは「日にち」と「予約が入ったか、なくなったか」だけです。
5. **いつもの見た目のまま**
   - 今の空き状況のページ（`reserve.html`）を、そのまま使います。
   - 色はお店の雰囲気（ベージュ＋ゴールド）に合わせます。
6. **手でも直せる**
   - 今まで通り、`availability.js` を書きかえて直すこともできます。
   - お休みの日は、これまで通り手で書きます。

※ これから決めること
- 1日に何件入ったら △（残りわずか）、何件で ×（満席）にするか
- 「確かめてOK」のお知らせを、どこで受け取るか（メール、スマホの通知など）

## 4. 今回は作らないこと
- ホームページから直接予約を受ける機能
  - 予約は、これまで通りホットペッパーだけで受けます。
- オーナーが OK を押さなくても勝手に変わる、全部自動の更新
- 時間ごと（何時に空いているか）の空き状況
  - 日にちごとの ◎△× だけにします。
- お客様の来店記録や、予約の前の日のお知らせ
- LINE や Instagram からの予約をまとめる機能
- スタッフと予約を分け合う機能

## 5. できたと言える状態
- ホットペッパーの予約のメールが届いたら、オーナーのところにお知らせが来る。
- お知らせに書いてあるのが、日にちと変える内容だけ。お客様の名前や電話番号は入っていない。
- OK を押すと、ホームページの空き状況がその通りに変わる。
- 「変えない」を選ぶと、何も変わらない。
- キャンセルのメールが来たら、空き状況をもどすお知らせが来る。
- 本物のお客様の情報を使わず、見本のメールで上のことを全部ためして、うまくいった。
- オーナーが、この説明書と使い方のメモを読んで、ひとりで使える。
