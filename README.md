# lesson-yamasita

レッスンの課題を回ごとにまとめるリポジトリです。

## フォルダ構成

```
lesson-yamasita/
├── lesson01/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── images/
└── lesson02/
    ├── index.html
    ├── css/
    │   └── style.css
    └── images/
```

## 新しい回を追加するとき

`lesson01/` をコピーして `lesson03/` のように番号を増やしてください。
