# lesson-yamasita

レッスンの課題を回ごとにまとめるリポジトリです。

## フォルダ構成

```
lesson-yamasita/
├── lesson01/
│   ├── index.html
│   ├── chapter2-slides.html   … 第2章「Webアプリのしくみ」スライド
│   ├── css/
│   │   └── style.css
│   └── images/
└── lesson02/
    ├── index.html
    ├── css/
    │   └── style.css
    └── images/
```

## 新しい回を追加するとき

`lesson01/` をコピーして `lesson03/` のように番号を増やしてください。

## スライドの操作

`lesson01/chapter2-slides.html` をブラウザで開きます。

- ← → キー / スペース：前後のスライドへ
- O：スライド一覧
- N：講師メモの表示 / 非表示
- スマホではスワイプで移動
